# Gartentraum Schröder — Brand Colors

Color palette sampled directly from the official logo. Use these for the
website, print, social media and any other brand material.

## 🌳 Greens (the tree)

| Name          | HEX       | RGB            | Role                              |
| ------------- | --------- | -------------- | --------------------------------- |
| Lime          | `#89C541` | 137, 197, 65   | Bright highlight / accent         |
| Fresh Green   | `#7FB142` | 127, 177, 66   | Secondary green                   |
| Brand Green   | `#5F8339` | 95, 131, 57    | **Primary brand green**           |
| Olive         | `#4D6A34` | 77, 106, 52    | Supporting green                  |
| Deep Forest   | `#445729` | 68, 87, 41     | Darkest logo green                |
| Forest (UI)   | `#1D2E22` | 29, 46, 34     | Near-black green for dark sections |

## 🟤 Browns (wordmark & trunk)

| Name     | HEX       | RGB           | Role                       |
| -------- | --------- | ------------- | -------------------------- |
| Tan      | `#90684D` | 144, 104, 77  | Light bark / highlight     |
| Brown    | `#885F41` | 136, 95, 65   | **Main wordmark brown**    |
| Earth    | `#85563A` | 133, 86, 58   | Warm earth tone            |
| Bark     | `#5E3C1E` | 94, 60, 30    | Darkest trunk tone         |

## Neutrals

| Name  | HEX       | RGB            | Role                  |
| ----- | --------- | -------------- | --------------------- |
| Cream | `#FAF8F3` | 250, 248, 243  | Page background       |
| Sand  | `#F5F1E8` | 245, 241, 232  | Section background    |
| Stone | `#8A8578` | 138, 133, 120  | Muted text / borders  |

## Suggested usage

- **Primary / CTA green:** `#5F8339` (use `#445729` / `#1D2E22` for dark buttons & sections)
- **Accent / highlight:** `#89C541` (underlines, icons, active states)
- **Earthy accent:** `#885F41`, with `#5E3C1E` for depth
- **Text on light:** `#1D2E22` · **Backgrounds:** `#FAF8F3` / `#F5F1E8`

Developer tokens are available as CSS custom properties in
[`styles/brand.css`](./styles/brand.css) and as the Tailwind `brand` /
`clay` / `bark` color scales in [`tailwind.config.ts`](./tailwind.config.ts).

A visual, shareable version of this sheet is published at
**`/marke.html`** on the live site.
